# HR 数据看板 v8 — 使用指南

> v8 · SWC HRBP 工作台 · 冷色调分色相 · 三类人群分开统计 · 本地缓存 · 断网可用

## 视觉规范（v8.4 改版）

**语义色（公司口径）**——红=好、绿=不好、黄=警告，与常规看板相反：

| 语义 | 浅色主题 | 深色主题 | 用在哪 |
|---|---|---|---|
| 好 / 正向 | `#dc2626` 红 | `#f87171` | 净增、转正率、逾期未转正（0 时算好） |
| 不好 / 负向 | `#16a34a` 绿 | `#4ade80` | 离职率、累计离职、实习/外协流出 |
| 警告 | `#d97706` 黄 | `#fbbf24` | 90 天届满、待办预警、合同到期 |

**主题色**——蓝色系保持不变：品牌蓝 `#2563eb`（按钮/导航/强调），图表主序列用亮蓝 `#3b82f6`。

**分类色板**（s1–s6，全色相，同一张图两两感知色差 ΔE ≥ 23）：

| 槽位 | 浅色主题 | 深色主题 | 用途 |
|---|---|---|---|
| s1 | `#3b82f6` 蓝 | `#60a5fa` | 主力：在职、部门、编制 |
| s2 | `#9333ea` 紫 | `#e879f9` | 总人数、外协人群、性别 |
| s3 | `#be185d` 玫红 | `#fb7185` | 岗位序列、对比色 |
| s4 | `#c2410c` 橙 | `#fb923c` | 试用期、转正届满 |
| s5 | `#ca8a04` 金 | `#facc15` | 平均司龄、合同类型 |
| s6 | `#65a30d` 橄榄 | `#a3e635` | 外包+劳务、实习签约 |

- **用工类型 6 类**复用上面 6 个色相：正式=蓝 · 试用期=橙 · 签约实习=橄榄 · 非签约实习=金 · 外协=紫 · 劳务=玫红
- **绩效等级 7 级**（SA→D）：深红→红→橙→黄→黄绿→绿→深绿，好=红、差=绿，跟随公司口径
- **合同到期 3 档**：≤30 天深黄 → 31-60 黄 → 61-90 浅黄（强度梯）
- 红绿不进分类色板，专留给语义；所有配色浅色/深色都过了感知色差校验

**字体**——全站统一为一种：**Noto Sans SC**（含拉丁与数字），已本地化到 `vendor/fonts/noto-sans-sc/`，不再出现「拉丁走西文字体、中文走系统字体」的混排。

**图标**——全部换成 **Google Material Symbols Outlined**，已本地化到 `vendor/fonts/material-symbols/`，导航、按钮、预警、表头排序都用同一套图标。

> 字体与图标资源都随文件夹一起走，**断网、不装字体也能正常显示**。

## 这个版本变了什么

v8 的核心是**口径**。以前看板把所有人混在一起算，会出现「看板说在职 311，领导手里是 258」的对不上账。现在：

| 人群 | 包含 | SWC 在职 |
|---|---|---|
| **正式员工** | 已转正 + 试用期 | **258** |
| **实习生** | 签约实习生 + 非签约实习生 | **26** |
| **外协 OD** | 外包人员 + 劳务人员 | **27** |

公司口径的「在职人数」= 正式员工，**不含实习与外协**。
每个指标旁都挂着**口径徽标**：`正式` / `正式+实习` / `全员`——一眼看出这个数含不含实习和外协。

## 快速上手

1. **双击打开** `v8/index.html`（无需安装，断网也能用）
2. 把 Excel **拖进上传区**（可整文件夹：人员数据 + 绩效 + 台账一起丢进去，自动识别）
3. 完成。下次打开**不用重新上传**——数据缓存在本机浏览器（IndexedDB）

- **默认锁定 SWC 中心**（筛选栏里随时可切到其他中心）
- **更新数据**：顶栏「上传人员数据」选新文件即覆盖缓存
- **绩效数据**：支持按中心分批上传，按工号自动合并，顶栏显示真实覆盖率
- **台账数据**：顶栏「上传台账」选 `SWC最新人才现状-*.xlsx`
- **清除缓存**：开发者工具 → Application → IndexedDB → 删除 `hr-dashboard-v8`

## 筛选栏

`人群`（全部 / 正式员工 / 实习生 / 外协 OD）· `状态` · `中心` · `部门`（二级部门）· `地点` · `用工`（6 类）· `入职` 日期区间。
所有筛选器联动，右侧实时显示「N 人 · 在职 X（正式 a · 实习 b · 外协 c）」。

## 9 个页面

| 页面 | 用途 |
|------|------|
| **总览** | 三块人群概览卡（含各自近 12 月流入/流出）、正式员工滚动离职率、净增、司龄、部门编制分布 |
| **组织与用工** | 职级分布、岗位序列；**部门透视表**——18 个二级部门 × 在职/正式/实习/外协/滚动离职率/平均司龄/主要职等，一张表看完 |
| **人员结构** | 年龄 / 司龄 / 学历 / 性别 / 工作地点 / 社会经验 vs 司龄（默认正式员工口径） |
| **人员流动** | **正式员工**分月离职率、离职职级与时长、**三块人群流出对照**（实习与外协只显示人数，不算率） |
| **转正与合同** | 转正日历（90 天届满）、逾期未转正、合同/协议到期分级（≤30 / 31-60 / 61-90 天） |
| **梯队绩效盘点** | 人才九宫格（梯队 × 半年度等级）、等级分布、历史趋势、投入系数、排名明细 |
| **职级健康度** | 职级金字塔、双通道结构、各中心职级对比 |
| **HR 工作台账** | **招聘缺口看板**（26 条待招）· **末位改进跟踪**（20 人六期绩效+计划+结论）· **储备干部池**（16 人）· **高潜名单**（40 人含最快晋升年限）· **外协 OD 台账**（在岗 25 / 离岗 7）· **本年度入职**（34 人）· **27 届校招需求**（13 个方向）· **部门梯队分组** |
| **员工明细** | 全字段表（新增「人群」列）：点列头筛选、排序、分页、CSV 导出与所见一致 |

## 预警系统（8 条，遵循当前筛选器）

1. 新员工访谈（80–105 天）· 全员
2. 试用期届满提醒（前 30 天）· 正式
3. **逾期未转正** · 正式
4. **合同/协议到期（90 天分级）** · 全员
5. 连续 3 次 B 及以下（动态最新 3 期）· 正式
6. 绩效连续下降（动态最新 4 期）· 正式
7. 高绩效低职级 · 正式
8. 外协/劳务长期在岗 · 外协

点「查看」跳明细表并自动过滤；点 ✕ 本次会话不再提示。每条预警标题旁标注了口径范围。

## 简报模式

顶栏「简报模式」→ 一页汇报（KPI + 三块人群 + 预警摘要 + 4 图）→「打印 / 存 PDF」出月报。

## 口径规则（重要）

- **离职率只算正式员工**：实习生「到期离岗」是正常退出，外协换人是供应商行为，混进来会把数字推高到失真
- 实习与外协只在概览卡与流动页显示「在册 N · 本期流出 M」，**不计算比率**
- 合同/协议到期是全员口径（因为实习协议、外包协议同样需要跟踪）
- 结构类图表（年龄/学历/职级/健康度）默认正式员工；若在筛选栏明确选了「实习生」，则按其选择展示

## 已知边界

- 绩效数据仅覆盖已上传文件的中心梯队人员（页面如实标注来源与覆盖率）
- 台账文件的 **sheet 名称与表头需保持稳定**，否则解析器识别不到
- KPA 导出暂无「离职原因」字段——解析器已预留，导出加上后流动页自动支持归因
- 无编制数 / 薪酬数据，故无编制达成率与人效指标
- KPA 与台账的外协人数可能差 1–2 人（数据口径时点不同），台账页会并列显示两个数供核对
